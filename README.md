# THỰC HÀNH – MÔ PHỎNG HỘI THOẠI PHÂN NHÁNH
### Thử thách bản lĩnh – Biết nói "KHÔNG" trước áp lực từ bạn bè

Ứng dụng web tương tác mô phỏng 3 tình huống kỹ năng sống dành cho học sinh:
1. **Áp lực bạn bè**: Rủ rê sử dụng thuốc lá điện tử (Pod) ngụy trang ma túy.
2. **Lời mời bất ngờ**: Lời mời uống trà sữa/đồ uống lạ ở cổng trường học.
3. **Đồ vật đáng ngờ**: Gói đồ lạ không rõ nguồn gốc trong lớp học.

---

## 🚀 Tính Năng Nổi Bật

- **Mô phỏng hội thoại phân nhánh**: Học sinh chọn các phản ứng khác nhau và nhận phản hồi tức thì với Điểm Bản Lĩnh Thám Tử.
- **Hệ thống âm thanh hiệu ứng (Web Audio API)**: Âm thanh click, chuông chúc mừng, cảnh báo, âm thanh môi trường trường học (có thể bật/tắt dễ dàng).
- **Giao diện hiện đại & thân thiện**: Thiết kế tối ưu cho học sinh trên mọi thiết bị máy tính, iPad, điện thoại.
- **Sẵn sàng triển khai trên Vercel**: Kiến trúc Vite + React thuần Client, không phụ thuộc server, tải trang siêu nhanh.

---

## 🛠️ Hướng Dẫn Chạy Cục Bộ

1. Cài đặt các gói phụ thuộc:
   ```bash
   npm install
   ```

2. Chạy môi trường phát triển (Dev server):
   ```bash
   npm run dev
   ```

3. Kiểm tra kiểu TypeScript & Build sản phẩm:
   ```bash
   npm run lint
   npm run build
   ```

---

## 🌐 Triển Khai Lên Vercel

1. Đẩy mã nguồn lên GitHub.
2. Truy cập [vercel.com](https://vercel.com) và chọn **Import Git Repository**.
3. Chọn framework preset **Vite**.
4. Nhấn **Deploy** (hệ thống sẽ tự động build và xuất bản trang web).
